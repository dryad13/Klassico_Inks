# Product PDF Downloads

Drop TDS and SDS PDF files here. Use this naming convention:

Ink series:
- `lam-series-tds.pdf` / `lam-series-sds.pdf`
- `h-lam-series-tds.pdf` / `h-lam-series-sds.pdf`
- `pel-series-tds.pdf` / `pel-series-sds.pdf`
- `max-series-tds.pdf` / `max-series-sds.pdf`
- `peak-series-tds.pdf` / `peak-series-sds.pdf`
- `kwb-series-tds.pdf` / `kwb-series-sds.pdf`
- `dgi-series-tds.pdf` / `dgi-series-sds.pdf`

Ink processes:
- `rotogravure-inks-tds.pdf` / `rotogravure-inks-sds.pdf`
- `flexographic-inks-tds.pdf` / `flexographic-inks-sds.pdf`
- `water-based-inks-tds.pdf` / `water-based-inks-sds.pdf`
- `offset-inks-tds.pdf` / `offset-inks-sds.pdf`

Solvents & industry products:
- `solvents-blends-tds.pdf` / `solvents-blends-sds.pdf`
- `pigments-tds.pdf` / `pigments-sds.pdf`
- `titanium-dioxide-tds.pdf` / `titanium-dioxide-sds.pdf`
- `resins-tds.pdf` / `resins-sds.pdf`
- `nitrocellulose-tds.pdf` / `nitrocellulose-sds.pdf`
- `solvent-dyes-tds.pdf` / `solvent-dyes-sds.pdf`

After adding files, update `tdsUrl` and `sdsUrl` in `src/data/products.js` for each product.
