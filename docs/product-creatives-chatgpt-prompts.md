# ChatGPT Image Prompts — Product Creatives

One prompt per product. In ChatGPT, start a **new message** (or new chat) for each image, paste the whole block, then download and save as `{slug}.webp`.

**Settings tip:** Ask for widescreen / 16:9. If ChatGPT offers size options, pick the widest landscape.

**Save as:** `src/assets/products/{slug}.webp`

---

## Shared rules (already baked into each prompt)

Do not add extra text in the image. No logos, watermarks, or readable brand names. Dark industrial look.

## After you generate

1. Download each image.
2. Rename to the slug (e.g. `lam-series.png`).
3. Convert to WebP 1600×900 if you can (Squoosh / Photoshop).
4. Drop into `src/assets/products/` when ready to wire into the site.

Generate **ink series first** (7 prompts) if you want the catalog to look finished fastest.
